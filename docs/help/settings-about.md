# Settings: About

Version information and credits. Nothing here changes any behavior.

## What's on this page

- **SparkyBot version** and a **View on GitHub** link to the project page.
- **Credits & links**, in two groups:
  - **Tools SparkyBot uses** — ArcDPS creates the logs, GW2 Elite Insights parses them, and the GW2 EI Log Combiner builds optional whole-session reports. Each name links to its project.
  - **Independent neighboring tools** — other WvW log tools, listed for credit and interoperability, not as a claim that their code is bundled or that SparkyBot was based on them.
- **How these tools differ** — a link to a comparison document explaining what each neighboring tool does.

The same catalog is reachable from **Help → Other WvW Log Tools & Credits...**, and a small version box from **Help → About SparkyBot**.

## Common problems

- **Links don't open** — they open in your default web browser; check a browser is set as default in Windows.
- **Wondering which version you have** — it's right here, and also in **Settings → Updates → Current Version**.

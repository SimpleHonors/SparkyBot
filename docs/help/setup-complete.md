# Setup: Ready to go

The last screen of the setup wizard. It confirms SparkyBot is configured and ready.

## What's on this screen

- **A summary of what was set up.** If you used a guild setup file or imported from another log tool, the checklist shows exactly what was taken care of — for example which Discord channels reports go to, that AI, voice, and Twitch are off, that this computer's parser and fight-log folder are ready, and that the other tool's files were not changed.
- **Finish and Open SparkyBot** — saves everything and opens the main window. Then click **Start Run** on the Home page when you begin playing (or **Start Watcher** if you chose to pick fights yourself).

## Common problems

- **"Setup Was Not Saved"** — SparkyBot could not write its settings on this computer. Nothing was finished. Check that the program folder is writable (for example, not blocked by antivirus or installed in a read-only location) and click Finish again.
- **Want to change something you just set?** — every choice from the wizard lives in **Settings** (gear entry in the sidebar, or `Ctrl+,`). You never need to re-run the wizard.

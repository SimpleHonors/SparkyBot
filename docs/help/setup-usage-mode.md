# Setup: How do you want to make your Combined Fight Log Summary?

The third screen of the setup wizard. A Combined Fight Log Summary (shown as **Fight Summary** in the app) is the single shareable stats page SparkyBot builds from a whole play session's fights. This screen asks how you'd like those summaries to be made.

## What's on this screen

- **One-button runs (recommended)** — the default. The Home page shows a **Start Run** button. Press it when you start playing; SparkyBot watches your log folder and counts every fight. When you're done, press **End Run** — SparkyBot builds the report and posts it for you. See [Home](home.md).
- **I'll pick fights myself** — no run button. You build reports on the [Fight Summary page](fight-log-summary.md) whenever you want, picking exactly which fights go in.

You can switch this any time in **Settings → Fight Summary**, under **How reports get made**. The change takes effect immediately — the run panel on Home appears or disappears when you save.

## Common problems

- **Not sure which to pick** — pick one-button runs. It's the least work, and the Fight Summary page still works in that mode if you ever want to hand-pick fights.
- **Picked one-button runs but no Start Run button on Home** — check **Settings → Fight Summary → How reports get made** is still set to **One-button runs (recommended)**.

# SparkyBot v2.0.0 — It Has a Front Door Now

SparkyBot used to be a very capable pile of tabs wearing a trench coat.
Version 2.0 gives it a proper Home screen, a clean dark interface, and a
workflow that makes sense before your third cup of coffee.

## Start Run. End Run. Report done.

Press **Start Run** when your squad starts. Press **End Run** when the
questionable decisions are over. SparkyBot remembers the run if it restarts,
counts the fights, builds the Raid Report, and can post it to Discord.

You raid. It handles the paperwork.

## Raid Reports without the ritual

Pick the last 12 hours, today, or only the fights you want. SparkyBot reuses
work it already did while watching the raid, so reports build faster instead
of grinding through everything twice. The finished report is one shareable
HTML file with the dashboards, breakdowns, and receipts your squad deserves.

Big reports also shrink themselves before posting. Discord may still judge
your file size, but it has fewer grounds for appeal.

## A real Home screen

The new activity feed shows posted fights, skipped fights, commentary, voice,
and reports in one place. It now says when a new fight was detected and is
being processed too, because staring at silence and hoping is not a status
screen. Drop `.evtc` or `.zevtc` files straight onto the window for a manual
run. Settings now use plain categories instead of asking you to remember
which ancient tab owns which checkbox.

![SparkyBot v2 Home](../screenshots/v2-home.png)

## AI is opt-in. Actually opt-in.

The setup wizard asks before configuring AI. Say no and the AI Commentary,
Voice, Vocabulary, and Calibration screens disappear completely. SparkyBot
still handles fight reports and Raid Reports just fine. Change your mind
later if you want the robot sports commentator back.

The wizard's choices are now full clickable cards, checkboxes have stopped
camouflaging themselves as punctuation, and local TTS has an **Add Voice**
button right where a reasonable person would look for it.

![Clear first-run choices](../screenshots/v2-setup-ai-choice.png)

![Add a local voice during setup](../screenshots/v2-setup-local-voice.png)

Empty Raid Report and Calibration pages also explain what they need and hand
you the correct big green button. Revolutionary technology: directions.

## Native Windows installer

Download the installer, double-click it, and launch SparkyBot. No Python
installation. No command line. No pretending `pip` is a normal thing to ask
of someone who just wants fight reports.

## Also better under the hood

- Faster cached Raid Reports with honest progress and useful error details.
- Smaller self-extracting reports that usually post to Discord as plain HTML.
- Persistent records and a Poison Coverage page for the dedicated cloud
  enjoyers.
- Safer report names and hardened report packing.
- Temporary reports clean themselves up instead of quietly founding a
  storage empire.
- Fewer console-window jump scares.
- Raid Report and Calibration now remember to actually appear when clicked.
- AI connection tests stop promptly, and DeepSeek no longer turns one test
  button into a three-minute guided meditation.
